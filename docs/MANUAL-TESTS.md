# Ручные проверки перед релизом

Автотесты (`npm test`) проверяют логику и интерфейс в имитации браузера. Здесь то, что видно только в живой SillyTavern 1.19.0+. Проверять на ПК, с открытой консолью (F12): строк с ошибками `[Kulisy]` быть не должно.

## Загрузка и соседство

- [ ] Расширение загружается без ошибок в консоли.
- [ ] Кнопка с масками стоит в верхней панели сразу после кнопки персоны; пункт «Кулисы» есть в меню палочки и в настройках расширений. После перезагрузки ничего не дублируется.
- [ ] При включённом Движке отношений при запуске появляется предупреждение о двойных отношениях. После выключения Движка и перезагрузки предупреждения нет.
- [ ] Чат, начатый в Движке, открывается в Кулисах с теми же персонажами, линиями и воспоминаниями. После свайпа старого проанализированного ответа его изменения откатываются.

## Тема и окно

- [ ] Цвета окна, виджета, чипов и плашек следуют теме. Сменить тему в настройках SillyTavern: Кулисы перекрашиваются без перезагрузки. Проверить на светлой и тёмной теме.
- [ ] Окно: Esc закрывает, Tab ходит по кругу внутри окна.
- [ ] Пристёгнутая панель: чат виден и пишется; Esc в поле ввода не закрывает панель; ручка ширины тянется мышкой, стрелками и сбрасывается двойным кликом; ширина и режим переживают перезагрузку.
- [ ] Значок в верхней панели горит, пока Кулисы открыты, как бы их ни открыли.

## Сцена и знания

- [ ] Сыграть сцену двоих (Ран и Судзу говорят наедине), проверить ответ. В «Ленте событий» появилось событие со свидетелями, в «Сейчас в сцене» — место и присутствующие, чипы над полем ввода показывают их же.
- [ ] Вывести на сцену третьего (Майки). В «Что модель знает о сцене» есть `unknown[Майки]` с этим событием.
- [ ] Ран рассказывает Майки. После проверки ответа в досье Майки событие в «Знает» с пометкой «рассказ: Ран»; строка `unknown[Майки]` исчезла.
- [ ] Свайпнуть этот ответ: Майки снова «Не знает».
- [ ] Майки упоминает то, чего не знает. Под ответом плашка «Возможная утечка» с цитатой; во вкладке «Утечки» она же, число в меню. «Свайп» перегенерирует ответ, «Он знает» записывает знание и убирает плашку, «Не утечка» просто убирает.
- [ ] Чипы: клик убирает персонажа со сцены и выводит обратно; клик по «На сцене:» открывает Кулисы.

## Знакомства

- [ ] С привязанной персоной в досье любого персонажа персона идёт первой с пометкой «не знакомы (персона)»; в блоке модели — `strangers[… & персона]`.
- [ ] Сыграть знакомство (представились). После проверки ответа статус — «знакомы», строки `strangers` нет. Свайп возвращает «не знакомы».
- [ ] Скан лорбука на знакомства: список с цитатами, после подтверждения статусы записаны; ручные отметки не изменились.

## Отношения (наследие Движка)

- [ ] Направленная пара, её шкалы, обратная линия кнопкой ⇅ независимы. Шкала «Семейная любовь» есть у каждой линии.
- [ ] «Факторы роста» → «Конечная точка»: «Предложить», сохранить; у обратной линии своя точка; в «Что получает модель» у строки линии `endpoint=`.
- [ ] «Сгенерировать по персонажу» опирается на анкеты и общие записи лорбука, включая книгу карточки.
- [ ] Хедканоны: открыть группу из троих, сгенерировать; групповые факты уходят модели, только когда в сцене все трое.
- [ ] Анализ истории в начатом чате, подтверждение крупного скачка, «Только мелкие».
- [ ] Экспорт → импорт в другой чат; импорт экспорта из Движка.

## Жизненный цикл сообщений

- [ ] Один ответ не анализируется дважды при повторных событиях.
- [ ] Правка сообщения заменяет его записи (отношения и знания).
- [ ] Удаление сообщения из середины откатывает его записи; плашки утечек остаются на своих сообщениях.
- [ ] Смена чата: у каждого чата свои знания и отношения; незаконченный анализ старого чата не попадает в новый.

## Выключатели

- [ ] Выключенный летописец: после проверки ответа знания не меняются, отношения меняются.
- [ ] «Летописец отдельным запросом»: два запроса на ответ, результат тот же.
- [ ] Выключенная отправка знаний: блок `[KULISY — WHO KNOWS WHAT` исчезает из промпта; выключенная отправка отношений не убирает блок знаний.
- [ ] Выключенные чипы: ни чипов, ни плашек утечек.
- [ ] Выключенный автоанализ: никаких фоновых запросов к API.
